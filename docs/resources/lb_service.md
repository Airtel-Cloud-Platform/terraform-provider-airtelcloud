# airtelcloud_lb_service (Resource)

Manages an Airtel Cloud Load Balancer Service.

A Load Balancer Service is the top-level LB resource. Once created, attach one or more VIPs (`airtelcloud_lb_vip`) and Virtual Servers (`airtelcloud_lb_virtual_server`) to it.

## Example Usage

```terraform
resource "airtelcloud_lb_service" "example" {
  name        = "my-lb-service"
  description = "Production load balancer"
  network_id  = "35df162d-5211-4d58-84ed-6a499626949c"
  vpc_id      = "029ac9b8-d93e-4691-a7cb-2f651c607cfe"
  vpc_name    = "my-vpc"
  ha          = false

  timeouts {
    create = "15m"
    delete = "10m"
  }
}
```
